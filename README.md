# TimeSync 🌙

แอปช่วยจัดการการนอน — ประเมินความล้า คำนวณเวลานอน/ตื่นที่เหมาะสม ติดตามหนี้การนอนสะสม
เสียงผ่อนคลายก่อนนอน และเตือนสิ่งสำคัญที่ต้องทำในตอนเช้า

ทำงานได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ต้องต่ออินเทอร์เน็ต ข้อมูลทั้งหมดเก็บอยู่ในเครื่องคุณ (localStorage)

---

## วิธีเปิดใช้งาน

**วิธีที่ 1 — ดับเบิลคลิกไฟล์** `index.html` (ง่ายที่สุด)

**วิธีที่ 2 — เปิดผ่านเว็บเซิร์ฟเวอร์** (แนะนำ เพราะการแจ้งเตือนของเบราว์เซอร์จะใช้งานได้)

```bash
python -m http.server 8123 --directory TimeSync
```

แล้วเปิด http://localhost:8123

> ℹ️ ถ้าเปิดแบบ `file://` เบราว์เซอร์ส่วนใหญ่จะไม่อนุญาต Web Notification
> TimeSync จะสลับไปแสดงป๊อปอัปในหน้าเว็บแทนโดยอัตโนมัติ

## ฟังก์ชันหลัก

### 1. ระบุความเหนื่อยล้า 😴
กดอิโมจิ 1 ใน 5 ระดับ (สดชื่น → หมดแรง) TimeSync จะคำนวณให้ว่า:

- **ควรเข้านอนภายในเวลาใด** โดยดูจากเวลาตื่นประจำของคุณ ระดับความล้า และเวลาปัจจุบัน
  - ระดับล้ามาก จะถูกเลื่อนเวลานอนให้เร็วขึ้น 30–90 นาที
  - ถ้าเลยเวลาที่ควรนอนไปแล้ว จะบอกว่า "ตอนนี้เลย" พร้อมบอกว่าเลยมากี่ชั่วโมง
  - ถ้ายังเป็นกลางวัน จะแนะนำเวลานอนของคืนนี้ + แนะนำงีบสั้นถ้าล้าหนัก
- **เวลาตื่นที่เหมาะสม** (ล้าน้อย = 5 รอบ / ล้ามาก = 6 รอบ)
- คำแนะนำเฉพาะระดับความล้านั้น ๆ และบันทึกย้อนหลัง 7 วัน

### 2. คำนวณเวลานอนที่เหมาะสม ⏰
คิดจากรอบการนอน (sleep cycle) รอบละ ~90 นาที บวกเวลาที่ใช้กว่าจะหลับ

- **นอนตอนนี้** — กดปุ่มเดียว เห็นเวลาตื่นที่ควรตั้งนาฬิกาปลุกทันที
- **ระบุเวลาเข้านอน** — พิมพ์เอง หรือกดปุ่มเวลาลัด (21:00 – 01:00)
- **ระบุเวลาตื่น** — คำนวณย้อนกลับว่าควรเข้านอนกี่โมง

แต่ละตัวเลือกบอกจำนวนรอบ ระยะเวลานอนรวม และป้ายกำกับ (แนะนำ / พอได้ / ขั้นต่ำ)

### 3. หนี้การนอนสะสม 📊
บันทึกเวลาเข้านอน–ตื่นในแต่ละวัน แล้ว TimeSync จะเทียบกับ **ชาร์ตเวลานอนสากล**
(National Sleep Foundation — Hirshkowitz et al., 2015) ตามช่วงอายุของคุณ

- แสดงหนี้สะสมรวมเป็นชั่วโมง ในกรอบเวลา 7–30 วัน (ปรับได้)
- กราฟแท่งรายวัน + รายการบันทึกย้อนหลัง
- แผนคืนหนี้ที่ทำได้จริง เช่น "เข้านอนเร็วขึ้นคืนละ 1 ชม. ติดต่อกัน 6 คืน"
- การนอนเกินถูกนับชดเชยได้สูงสุดวันละ 1 ชม. เพราะร่างกายไม่ได้คืนหนี้แบบ 1:1

### 4. ผ่อนคลายก่อนนอน 🎵
เสียง 6 แบบที่ **สังเคราะห์สดในเครื่อง** ด้วย Web Audio API (ไม่มีไฟล์เสียง ไม่ต้องโหลด ไม่มีวันวนซ้ำ):
เสียงฝน · คลื่นทะเล · สายลม · กองไฟ · เปียโนกล่อมนอน · Brown Noise

- ตั้งเวลาปิดอัตโนมัติ (Sleep Timer) 5–60 นาที เสียงจะค่อย ๆ เบาลงก่อนดับ
- ปรับระดับเสียง และครอสเฟดเวลาสลับเสียง
- **ตัวช่วยหายใจ 4-7-8** พร้อมวงกลมนำจังหวะ 4 รอบ

### 5. สิ่งสำคัญที่ต้องทำพรุ่งนี้ 📝 (ฟังก์ชันเสริม)
จดงานก่อนนอน กำหนดระดับความสำคัญ (สำคัญมาก / ปกติ / ถ้ามีเวลา)
ตั้งเวลาเตือนตอนเช้า → TimeSync จะแจ้งเตือนพร้อมสรุปงานให้

> การแจ้งเตือนทำงานเมื่อเปิดหน้า TimeSync ค้างไว้ ถ้าปิดแท็บไป
> ระบบจะแสดงสรุปงานให้ทันทีที่คุณกลับมาเปิดในตอนเช้าแทน

## ตั้งค่า ⚙️

| ค่า | ค่าเริ่มต้น | ผลกระทบ |
|---|---|---|
| ช่วงอายุ | ผู้ใหญ่ตอนต้น (18–25) | เกณฑ์ชั่วโมงนอนที่ใช้คำนวณหนี้ |
| เวลาตื่นประจำ | 07:00 | ใช้คำนวณเวลาเข้านอนจากระดับความล้า |
| เวลากว่าจะหลับ | 15 นาที | บวกเพิ่มในทุกการคำนวณ |
| ความยาว 1 รอบการนอน | 90 นาที | ปรับได้ 80–110 นาที |
| ช่วงคำนวณหนี้ | 14 วัน | ปรับได้ 7–30 วัน |

ส่งออกข้อมูลเป็นไฟล์ JSON หรือล้างข้อมูลทั้งหมดได้จากหน้าตั้งค่า
