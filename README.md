# TimeSync 🌙

**เปิดใช้งานเลย → https://newhub01.github.io/TimeSync/**

แอปช่วยจัดการการนอน — ประเมินความล้า คำนวณเวลานอน/ตื่นที่เหมาะสม ติดตามหนี้การนอนสะสม
เสียงผ่อนคลายก่อนนอน นาฬิกาปลุก และเตือนสิ่งสำคัญที่ต้องทำในตอนเช้า

ไม่มี framework ไม่มี build step ไม่มี dependency ข้อมูลทั้งหมดอยู่ในเครื่องคุณเท่านั้น

## ⏰ ข้อจำกัดเรื่องการปลุก — อ่านก่อนใช้จริง

**เว็บแอปไม่สามารถปลุกตรงเวลาได้ถ้าปิดหน้าต่างไปแล้ว** นี่ไม่ใช่ข้อจำกัดของ TimeSync
แต่เป็นข้อจำกัดของทุกเบราว์เซอร์:

| ทางเลือก | สถานะจริง |
|---|---|
| Notification Triggers API | Chrome ทดลองแล้ว **ไม่ปล่อยใช้จริง** ไม่มีเบราว์เซอร์ไหนรองรับ |
| Web Push | ต้องมี backend server คอยยิง push — ขัดกับหลักการเก็บข้อมูลในเครื่องล้วน |
| Periodic Background Sync | Chrome เท่านั้น ขั้นต่ำ ~12 ชม. ใช้ปลุกไม่ได้ |

**สิ่งที่ TimeSync ทำได้จริง:**

- ตั้งเสียงปลุกไว้บนนาฬิกาของ **AudioContext** ซึ่งเบราว์เซอร์ไม่หน่วงเหมือน `setTimeout`
  → ปลุกตรงเวลาแม้แท็บอยู่เบื้องหลังหรือย่อหน้าต่างไว้
- เปิด keep-alive เงียบ ๆ ขณะตั้งปลุก กัน AudioContext ถูกระบบพักการทำงาน
- แจ้งเตือนผ่าน Service Worker ค้างอยู่ใน tray ของ Windows คลิกแล้วเด้งกลับมาที่แอป
- ถ้าเผลอปิดไป เปิดกลับมาภายใน **30 นาที** ยังปลุกให้อยู่

**วิธีใช้ที่ได้ผล:** ติดตั้งเป็นแอปแล้วย่อหน้าต่างทิ้งไว้ตอนนอน หรือเปิดแท็บค้างไว้

## ฟังก์ชัน

### 1. ระบุความเหนื่อยล้า 😴
กดอิโมจิ 1 ใน 5 ระดับ (สดชื่น → หมดแรง) แล้ว TimeSync คำนวณให้ว่า:

- **ควรเข้านอนภายในเวลาใด** จากเวลาตื่นตามตาราง ระดับความล้า และเวลาปัจจุบัน
  - ล้ามากจะถูกเลื่อนเวลานอนให้เร็วขึ้น 30–90 นาที
  - เลยเวลาที่ควรนอนแล้ว → "ตอนนี้เลย" พร้อมบอกว่าเลยมากี่ชั่วโมง
  - ยังเป็นกลางวัน → แนะนำเวลานอนของคืนนี้ + แนะนำงีบสั้นถ้าล้าหนัก
- **เวลาตื่นที่เหมาะสม** (ล้าน้อย = 5 รอบ / ล้ามาก = 6 รอบ)
- คำแนะนำเฉพาะระดับนั้น ๆ และบันทึกย้อนหลัง 7 วัน

### 2. คำนวณเวลานอนที่เหมาะสม ⏰
คิดจากรอบการนอน ~90 นาที บวกเวลาที่ใช้กว่าจะหลับ

- **นอนตอนนี้** — กดปุ่มเดียว เห็นเวลาตื่นที่ควรตั้งปลุก
- **ระบุเวลาเข้านอน** / **ระบุเวลาตื่น** — ค่าเริ่มต้นดึงจากตารางของคืนนี้ให้แล้ว
- ปุ่ม ⏰ บนแต่ละแถว = ตั้งปลุกเวลานั้นทันที ไม่ต้องเปิดหน้าใหม่

### 3. หนี้การนอนสะสม 📊
เทียบกับ **ชาร์ตเวลานอนสากล** (National Sleep Foundation, Hirshkowitz et al., 2015)

- หนี้สะสมรวมเป็นชั่วโมงในกรอบ 7–30 วัน (ปรับได้) + กราฟแท่งรายวัน
- แผนคืนหนี้ที่ทำได้จริง เช่น "เข้านอนเร็วขึ้นคืนละ 1 ชม. ติดต่อกัน 6 คืน"
- นอนเกินชดเชยได้สูงสุดวันละ 1 ชม. เพราะร่างกายไม่ได้คืนหนี้แบบ 1:1
- **แบนเนอร์ยืนยันคลิกเดียว** — "เมื่อคืนนอน 23:30–07:00 ใช่ไหม? [ยืนยัน]"

### 4. ผ่อนคลายก่อนนอน 🎵
เสียง 6 แบบสังเคราะห์สดในเครื่อง (ฝน / คลื่นทะเล / สายลม / กองไฟ / เปียโน / brown noise)
**หมวดนี้สำหรับก่อนนอนเท่านั้น** — เสียงปลุกอยู่คนละแท็บ

- Sleep timer 5–60 นาที เสียงค่อย ๆ เบาลงก่อนดับ
- ปรับระดับเสียงแยกจากเสียงปลุก และครอสเฟดเวลาสลับเสียง

### 5. นาฬิกาปลุก ⏰
- เสียงปลุก 5 แบบ: บี๊บคลาสสิก / ไซเรนไต่ / ระฆังเร่ง / ดิจิทัล / ค่อย ๆ ปลุก
- ความดัง **เริ่มต้น 100%** แยกสไลเดอร์จากเสียงผ่อนคลาย
- Volume ramp-up 0/10/30/60 วินาที (ไต่แบบ ease-in)
- **อัปโหลดเพลงของตัวเอง** เก็บใน IndexedDB ในเครื่อง ไม่ส่งออกไปไหน
- เลื่อนปลุก 5/9/10/15 นาที จำกัดจำนวนครั้ง + แสดงงานสำคัญบนหน้าจอปลุก
- ปลุกตามตารางของแต่ละวันได้ (opt-in)

### 6. ตารางที่ไม่คงที่ 📅
- **โหมดง่าย** (ค่าเริ่มต้น) — เวลาเดียวใช้ทุกวัน
- **โหมดรายวัน** — ตั้งเวลาตื่น/เข้านอนแยกทีละวัน จ–อา
- **เฉพาะวันเดียว** — ตั้งเวลาพิเศษให้วันใดวันหนึ่งโดยไม่กระทบตารางประจำ
  (ที่เลยวันแล้วถูกลบทิ้งอัตโนมัติ)

### 7. เตือนอัตโนมัติ 🔔
ปิดได้ทีละตัวจากหน้าตั้งค่า:

| ตัวเตือน | เมื่อไหร่ | ตามเก็บได้ |
|---|---|---|
| บันทึกการนอน | เวลาที่ตั้งเอง | 6 ชม. |
| ก่อนถึงเวลานอน | ล่วงหน้า 0/15/30/60 นาที | 45 นาที |
| ยังไม่ได้ตั้งปลุก | ถึงเวลานอน | 1 ชม. |
| งานสำคัญตอนเช้า | เวลาที่ตั้งเอง | 6 ชม. |

"ตามเก็บ" = ถ้าปิดแอปอยู่ตอนถึงเวลา เปิดกลับมาภายในช่วงนี้จะยังได้รับการเตือน
แต่ละตัวยิงได้วันละครั้ง

### 8. งานสำคัญของพรุ่งนี้ 📝
จดก่อนนอนพร้อมระดับความสำคัญ แสดงบนหน้าจอปลุกตอนเช้าเลย

### 9. โปรไฟล์ผู้ใช้ 👤 (อยู่ในแท็บ ⚙️ ตั้งค่า)
ชื่อ · อายุ · เพศ · ส่วนสูง · น้ำหนัก — **ไม่มีช่องไหนบังคับ** บันทึกอัตโนมัติทันทีที่แก้

- **อายุที่กรอกเลือกช่วงวัยในชาร์ตเวลานอนสากลให้เอง** ไม่ต้องตั้งซ้ำสองที่
  (ยังแก้เองได้จากหน้าตั้งค่าถ้าอยากใช้เกณฑ์อื่น)
- คำนวณ BMI จากส่วนสูง–น้ำหนัก ใช้เกณฑ์ WHO Asia-Pacific ซึ่งจุดตัดต่ำกว่าเกณฑ์สากล
  เป็นตัวเลขอ้างอิงเฉย ๆ TimeSync ไม่เอาไปตัดสินใจอะไรแทนคุณ
- ชื่อที่กรอกใช้ทักทายบนหน้าจอปลุกและหน้าสรุปตอนเช้า
- ลบข้อมูลโปรไฟล์แยกต่างหากได้โดยไม่กระทบบันทึกการนอน

### สถาปัตยกรรม

ตรรกะการคำนวณทั้งหมดอยู่ใน `core.js` เป็น **ฟังก์ชัน pure ที่รับ config และ `now` เป็นพารามิเตอร์**
ไม่อ่าน global state และไม่แตะ DOM จึงเทสต์ได้โดยไม่ต้องมีเบราว์เซอร์
โหลดได้ทั้งใน browser (`<script>` → `window.TimeSyncCore`) และ Node (`require`)

`app.js` ทำหน้าที่แค่เอาผลลัพธ์ไปวาดหน้าจอ

## การเก็บข้อมูล

| ที่เก็บ | เก็บอะไร |
|---|---|
| localStorage `timesync.state` | บันทึกการนอน ความล้า ตาราง ตั้งค่า งาน |
| IndexedDB `timesync/sounds` | ไฟล์เสียงปลุกที่อัปโหลด |

โครงสร้าง state มีเลขเวอร์ชันและ migration chain — อัปเกรดจากเวอร์ชันเก่าได้โดยข้อมูลไม่หาย
ค่าที่เสียหายหรืออยู่นอกช่วงถูกซ่อมอัตโนมัติตอนโหลด

**สิ่งที่กรอกค้างไว้แต่ยังไม่ได้กดบันทึก** ก็ถูกเก็บไว้ด้วย เผลอปิดหน้าต่างแล้วเปิดใหม่
จะได้กลับมาครบ พร้อมแท็บที่ค้างไว้

ส่งออกเป็น JSON หรือล้างข้อมูลทั้งหมดได้จากหน้าตั้งค่า
